# Media notes

[← Overview](../README.md) · [Card gallery](Cards.md) · [Development status](Development.md)

Every image in these guides is an actual Foundry interface capture from a synthetic development scene. Character names, items, and roll results belong to that test data. Cropping isolates a native window or card; WebP conversion reduces download size. No UI was generated, repainted, or recreated for the documentation.

The public installer is **0.7.40**. **Capture version** identifies the source of an image, not the version currently installed in a reader’s world. **Audited preview** identifies the tested local revision shown in selected current screenshots; it does not claim a published 0.7.41 release. The gallery keeps older native examples where they illustrate a card family. Check the feature guides and [development status](Development.md) for behavior that differs in the preview.

## Reading these examples

- **Private views are labeled.** GM review, concentration requests, and some roll-request details are shown to explain those interfaces; their presence in this public guide does not change in-game visibility.
- **Only the rest GIF demonstrates motion.** Heat, turn prompts, and other gallery images are still screenshots; their montages show separate native states rather than an animation recording.
- **Synthetic data is visible.** QA labels, deliberate damaged items, and test roll values are native demonstration content, not a campaign export.
- **Defaults can differ.** Colors, text size, folding, rarity integration, and third-party module configuration can change what a reader sees.

The originals remain in the development audit. Documentation media contains no machine-specific file paths, campaign databases, QA result JSON, or recreated UI.
